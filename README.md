#Autovermietungssystem mit Python

Projektbeschreibung

Dieses Projekt ist ein einfaches Autovermietungssystem, das ich mit Python im Rahmen meiner Umschulung zum Fachinformatiker für Anwendungsentwicklung entwickelt habe.

Funktionen

* Auswahl eines Autos (BMW, Mercedes oder Audi)
* Eingabe des Kundennamens
* Eingabe der Mietdauer in Tagen
* Automatische Berechnung des Mietpreises
* 10 % Rabatt ab 7 Miettagen
* Bestätigung einer Buchung
* Anzeige der Buchungsdaten

Verwendete Technologien

* Python
* Dictionaries und Listen
* if-else-Bedingungen
* Schleifen
* try-except zur Fehlerbehandlung

Projektziel

Mit diesem Projekt möchte ich meine Python-Kenntnisse verbessern und praktische Erfahrungen in der Softwareentwicklung sammeln.
